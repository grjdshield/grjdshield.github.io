# GRJD Shield – Landing Page

Official website of **GRJD Shield**, a Random Forest-based browser extension for real-time phishing website detection.

Live site: https://grjdshield.github.io

| File / folder | Purpose |
|---|---|
| `index.html` | The landing page |
| `privacy.html` | Privacy policy |
| `style.css`, `script.js` | Design and page behavior |
| `images/` | Logo and screenshots |
| `downloads/PhishingDetection.zip` | The extension for manual install (Load unpacked) |
